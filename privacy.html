Privacy Policy

Last updated: 24 November 2026

Story Shorts Uploader ("the tool") is a personal tool used only by the owner of one YouTube channel to upload that owner's own videos. This policy explains what data the tool accesses and how it is handled.

YouTube API Services

The tool uses YouTube API Services. Google's handling of data is described in the Google Privacy Policy. Use of the tool is also subject to the YouTube Terms of Service.

What data the tool accesses

  • With the owner's permission (Google sign-in), the tool receives an access token for the owner's YouTube account with the scopes youtube.upload and youtube.
  • It uses them only to upload the owner's own videos with title, description, tags and privacy setting, to change the privacy setting of those videos, and to read their upload and processing status.
  • It does not read comments, subscribers, analytics, other channels or any data of other users.
  • Separately from YouTube, the tool may use the Google Drive scope drive.file to save copies of the owner's own finished videos into a "Story Shorts" folder in the owner's Drive. This scope only covers files the tool itself creates; it cannot see any other Drive files.

How data is stored

  • The access and refresh tokens are stored only on the owner's own devices or in the owner's own protected configuration. They are never published or shared.
  • The tool keeps no database of user data. Video IDs and titles may be kept in the owner's private project files to track what was uploaded.

Sharing

No data obtained through YouTube API Services is sold, shared with, or disclosed to third parties.

Cookies

This website and the tool do not use cookies or tracking.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. After revocation, stored tokens no longer work and are deleted from the owner's devices. Any stored data obtained from the API is deleted within 30 days at the latest, or sooner on request.
